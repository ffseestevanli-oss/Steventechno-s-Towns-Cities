# Steventechno's Towns & Cities!

*The Spiritual Successor to Steventechno's House Packs, Buildings Packs, Furniture Packs AND Electronics Packs, All in one massive, yet compact add-on!*

A new age of building in Garry's Mod is here!

**🌐 Website: [ffseestevanli-oss.github.io/Steventechno-s-Towns-Cities](https://ffseestevanli-oss.github.io/Steventechno-s-Towns-Cities/)** · **📖 [Player manual](https://ffseestevanli-oss.github.io/Steventechno-s-Towns-Cities/manual.html)**

This repository holds the website and player manual for **Steventechno's Towns & Cities!**, a Sims-style building tool for Garry's Mod.

- Website source: [`docs/`](docs/) (plain HTML, CSS and JS, no build step)
- Player manual: [`docs/manual/MANUAL.md`](docs/manual/MANUAL.md), shown on the site at `manual.html`
- Screenshot list: [`docs/SCREENSHOTS.md`](docs/SCREENSHOTS.md) and [`docs/manual/README.md`](docs/manual/README.md)

## Publishing with GitHub Pages

1. Repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*, branch `main`, folder `/docs`, and save.
3. The site appears at [https://ffseestevanli-oss.github.io/Steventechno-s-Towns-Cities/](https://ffseestevanli-oss.github.io/Steventechno-s-Towns-Cities/) a minute later.

See [`docs/README.md`](docs/README.md) for how to add screenshots and fill in the Workshop links.
