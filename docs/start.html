Get started

Start building in a minute

Subscribe, load any map and press F3. Everything below is optional reading for when you want to go further.

Install Packs it works with Your first house Controls Admin and servers
Step 1

Install

  1. Subscribe on the Steam Workshop. (Or copy the st_homeconstruct folder into garrysmod/addons/.)
  2. Start any map. Flat maps like gm_flatgrass or gm_construct are the perfect canvas.
  3. Find it in the spawn menu under Tools → Construction → Steventechno's Towns & Cities.
  4. Press F3 for Build mode or F2 for Furnish mode. Press the other key to switch, and F1 to leave.
Subscribe on the Workshop
Step 2 (optional)

Steventechno's packs it works with

Towns & Cities works on its own: it ships with its own walls, doors, roofs, roads, textures and more than a hundred built-in furniture pieces. Subscribe to Steventechno's packs as well and even more appears. Furnish and the paint picker only show what you have installed.

Running a server? The server needs the packs too. Add them with resource.AddWorkshop (for example resource.AddWorkshop( "455282752" ) and resource.AddWorkshop( "106229933" )) so players download them when they join. After enabling a pack mid-game, run sthc_furnish_rescan.

Step 3

Your first house in eight steps

  1. Flooring → LotsDrag a lot on open ground. 12x10 is a good first house.
  2. Flooring → FoundationOptional: pick a height and drag it over the lot.
  3. WallsHold Shift and drag to outline the house, then drag inner walls for rooms.
  4. DoorsPick a front door and click an outside wall. Add inner doors.
  5. WindowsClick windows onto the walls, dragging up or down for the height.
  6. RoofsPick Gable, a pitch and shingles, then drag over the whole house.
  7. PaintPaint the outside, then use Room fill on each room's walls and floor.
  8. FurnishPress F2, pick a sofa, press where it goes and drag to turn it.

For admins

Admin and server commands

Most of these are also buttons in the build interface's top bar (Save, Limits, Settings).

Saves
sthc_save / sthc_loadSave now / load the last save
sthc_autosave 0|1Auto-save on or off
sthc_autoload 0|1Load the save when the map starts
sthc_autosave_interval <s>Seconds between saves (0 = only on shutdown)
sthc_remove_all confirmRemove everything
sthc_lot_remove <id>, sthc_bulldoze <id>Remove one lot
sthc_set_max_floors <1-16>Max floors per building (default 8)
Multiplayer
sthc_unlock <name> / sthc_lock <name>Lift or restore a player's limits
sthc_unlockedList unlocked players
